# ZeroTrace

ZeroTrace is a production-ready, Windows-only, portable Electron application for discovering installed software, uninstalling apps, and detecting/removing leftovers safely. It runs fully offline and stores all operational data locally for portable usage.

## Project Overview

ZeroTrace provides:
- Registry + UWP app discovery via PowerShell
- Fuzzy search and sorting
- Standard and force uninstall modes
- Batch uninstall queue
- Leftover scanning with confidence scoring
- Snapshot capture and diff engine
- Bloatware detection using local rules
- Real-time IPC progress updates
- Portable data/log/snapshot storage

## Features

### 1) App Discovery Engine
- Reads installed applications from:
  - `HKLM:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*`
  - `HKLM:\Software\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*`
  - `HKCU:\Software\Microsoft\Windows\CurrentVersion\Uninstall\*`
- Reads UWP packages with `Get-AppxPackage`
- Normalized output fields:
  - name, version, size, sizeBytes, installDate, installLocation, uninstallString, publisher, source

### 2) Instant Search + Sorting
- Fuzzy search with Fuse.js
- Sort options:
  - Name
  - Size
  - Install date

### 3) Uninstall Engine
- Executes discovered uninstall strings
- Attempts silent uninstall switches when supported
- Waits for command completion and reports result

### 4) Progress System
- IPC events stream real-time steps:
  - Uninstalling
  - Scanning leftovers
  - Cleaning

### 5) Batch Uninstall Mode
- Multi-select table checkboxes
- Sequential uninstall queue processing

### 6) Advanced Leftover Scanner
Scans:
- Program Files
- Program Files (x86)
- AppData Local
- AppData Roaming
- Temp
- HKCU/HKLM software registry roots

Logic:
- Name normalization + fuzzy token matching
- Publisher token influence
- Path similarity boost
- Confidence scoring and sorted output

Safety:
- Candidates are shown to users; nothing is auto-deleted without user confirmation in UI workflow.

### 7) Snapshot-Based Engine
- Capture filesystem/registry baseline into `/data/snapshots`
- Compare before/after snapshots
- Returns new files/registry keys

### 8) Force Uninstall Mode
- Attempts to terminate matching running processes
- Removes install directory
- Removes matching non-shared keys (skips obvious Microsoft/Windows keys)
- If deletion is blocked, attempts mark-for-delete-on-reboot behavior

### 9) Portable Mode
- No AppData usage for app state
- Local folders only:
  - `/data`
  - `/logs`
  - `/data/snapshots`

### 10) Bloatware Detector
- Local JSON rule set in `data/bloatware-list.json`
- Detects known junk signatures
- Flags large apps with unknown usage signal

## Usage

1. Launch the app.
2. Refresh and inspect discovered applications.
3. Search and sort to identify targets.
4. Select app(s) for standard uninstall or batch uninstall.
5. Use **Scan Leftovers** to review confidence-ranked residual artifacts.
6. Use **Force Uninstall** for stubborn applications (with caution).
7. Run snapshots before/after a change for precision detection.
8. Use bloatware detection to highlight likely removal candidates.

```bash
npm install

  "productName": "ZeroTrace",
  "win": {
    "target": "portable"

```

## Safety Notes

- ZeroTrace never deletes leftovers automatically without explicit user actions.
- Force mode is powerful and should be used only when normal uninstall fails.
- Shared/system registry paths require caution; script logic avoids obvious shared Microsoft/Windows keys.
- Run as administrator for operations requiring elevated access.
- Offline-only architecture: no cloud calls or remote backend.
